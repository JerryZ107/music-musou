# ADR 0016 — 三角色攻击模组重调（扇砍 / 戳击 / 护盾）

**结论**：在 ADR 0015 三角色套装之上，重调近战形态与距离。**铁铠武士**普攻/强化普攻为 **90° 自动锁敌挥砍**，攻击距离与刀长为改前的 **1/3**（r=4/3）；大招改为 **7 秒护心**：每秒获得 1 点护盾，**上限 1**。**青衫枪客**普攻为 **自动锁敌直线戳击**，攻击距离与枪长为改前的 **2/3**（r=4）；大招改为 **7 秒枪势**，期间普攻使用武士改前的 **全圆 r=4**。**灵耳弓使**弹程为改前的 **1.6 倍**（16）。全角色 **普攻与位移共用 0.4 秒**动作间隔。

**为啥**：近战全圆/半圆清场过满，需要更短、更指向性的刀枪，并用护盾/全圆窗口拉开大招身份。共用间隔避免普攻与滑步连打。

| 谁 | 记什么 |
|----|--------|
| **前端** | 武士 90° 刀光、枪客戳刺线、枪势期间全圆旋枪；武士护盾有 HUD 点与身周环。 |
| **后端** | 武士扇形半角 45°；枪客线段胶囊；枪势全圆 r=4；护盾先于 HP 吃接触伤；`lastAttackMs` 与 `lastSlideMs` 互相卡住 400ms。 |

**别做**：武士大招再打全圆爆发；枪势再叠半圆加伤加半径；给普攻和滑步两套不同 CD。

**取代关系**：覆盖 ADR 0015 的攻击距离「旧模组 ×2」以及武士全圆 / 枪客半扫 / 武士破军全圆 / 枪势半圆强化的具体形态。0015 的三角色、一条命、切人不停歌仍有效。

**相关**：0012、0013、0015
