# ADR 0010 — 一局一首歌，可多人机制

> ⚠ 部分被 [0011](./0011-single-character-multi-weapon-attack-modules.md) 取代：「多 Hero 换人」→「单角色多武器切换」；「一局一曲」结论不变。

**结论**：**Run 里只有一首 Track**（一条 BGM + 一张拍子表）。一关可以多个 **Hero**，局中**可以换人**，但**不能换歌**。想换歌 → 新 Run / 回选关。

**为啥**：Run 内换歌会卡在「续播还是重播」；把 **歌（Build/拍子）** 和 **人（机制）** 拆开就简单了。

| 谁 | 记什么 |
|----|--------|
| **前端** | 节拍 HUD 只跟 `track_id` + 播放时间，**不跟** `hero_id`。换人：不切 BGM、不重置拍子条。选关页写清「本关曲目 + 可选英雄」。 |
| **后端** | `track_id` 从开局到结束不变。`hero_id` 可变。换人默认：**清掉进行中的大招 Buff**；大招条**保留**（除非配置 `hero_switch_reset_energy`）。 |

**配置要点**：`track` 有 `bgm`、`beat_map`；`hero` **没有**自己的 `bgm`。`stage.allowed_heroes[]` 管谁能选。

**别做**：每人一首歌；换人时歌从头播；Run 内无确认换 Track。
