# ADR 0007 — 卡拍只分两档，窗要宽

**结论**：只有 **在窗内 / 不在窗内**，没有 Perfect、Good。**窗偏宽**，照顾延迟和走位。

拍子表跟 **Track** 走；**换 Hero 不换窗、不换拍子表**（0010）。

| 谁 | 记什么 |
|----|--------|
| **前端** | 亮区宽度 = 逻辑窗宽；输入时间和 BGM 时间用**同一时钟**；可按歌调音频延迟 `[` `]`。 |
| **后端** | HUD 和伤害判定用**同一套** `in_window`；可选短 grace（Demo 约 55ms）。 |

**别做**：多档判定叠乘充能（变音游）。

**相关**：0001、0010
