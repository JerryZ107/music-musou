# ADR 0008 — 卡拍 = 双倍伤 + 双倍充能

**结论**：**Beat-On Hit** 相对 **Basic Hit**：伤害 **×2**，每次 Grant 也 **×2**（仍受 0003 人头 Cap 限制）。

**小兵**：HP=2、基础伤=1 时 → 不卡拍 **2 刀**、卡拍 **1 刀**。  
**Boss**：只看血条；卡拍仍是双倍扣血。

Hero 可以整体伤害减半之类，但**同一 Hero 内**卡拍始终是普通的 2 倍。

| 谁 | 记什么 |
|----|--------|
| **前端** | 教程写清「卡拍双倍」；Boss 血条按实际扣量跳。 |
| **后端** | `damage *= 2 if beat_on`；Grant 同理。 |

**别做**：只双倍充能、伤害不变。

**相关**：0001、0002
