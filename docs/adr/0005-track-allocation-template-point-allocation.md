# ADR 0005 — 一首歌一套加点

**结论**：**1 Track = 1 Allocation Template**（能点哪几条、基础值、总 Cap）。同歌差别靠 **x/y 怎么分**；换歌 = 换模板和大招类型。

**为啥**：「练这首、点这首」；和换 Hero（机制）分开。

| 谁 | 记什么 |
|----|--------|
| **前端** | 加点页标题是**当前这首歌**；换歌走选关/新 Run，别和局中换人混一屏。 |
| **后端** | 战斗数值 = Hero 机制 + `resolve(loadout)`。 |

**别做**：全局一套加点套所有歌。

**相关**：0006、0010
