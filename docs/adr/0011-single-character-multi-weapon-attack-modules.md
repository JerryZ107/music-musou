# ADR 0011 — 单角色一条命，多武器切换（攻击模组）

> ⚠ 「机制全在武器上、只有一个外形」已被 [ADR 0015](./0015-three-heroes-kits.md) 取代。本篇仍有效的是：**一条命、切模组不停歌、不重载拍子表**。

**结论**：玩家为**单角色、一条命**；Run 内可切换**多种武器**，不同武器拥有不同**攻击模组**（普攻形状、滑步、大招表现）。换武器**不停歌、不重载拍子表**。Run 内 HP=0 失败，可选**观看广告复活一次**（次数 / 条件待定）。

**为啥**：原「多 Hero 换人」把角色变成可切换资源，身份与成长耦合。改为「角色固定、机制在武器上」，机制差异保留、身份单一，并为一条命 + 复活变现留出结构。

| 谁 | 记什么 |
|----|--------|
| **前端** | 节拍 HUD 只跟 `track_id` + 播放时间，**不跟** `weapon_id`。切武器：不切 BGM、不重置拍子条。UI 显示当前武器与切换入口。 |
| **后端** | `track_id` 从开局到结束不变；`weapon_id` 可变。切换默认：**清掉进行中的大招 Buff**；大招条**保留**（除非配置 `weapon_switch_reset_energy`）。HP 为 Run 级单值；HP=0 进入失败 / 复活流程。 |

**配置要点**：`track` 有 `bgm`、`beat_map`；武器**没有**自己的 `bgm`。`stage.allowed_weapons[]` 管本关能用哪些武器。

**别做**：每把武器一首歌；切武器时歌从头播；Run 内无确认换 Track；武器做成永久养成（v0）。

**取代关系**：**取代 ADR 0010 的「多 Hero 换人」部分**；0010 的「一局一曲」结论保留。
