# ADR 0003 — 一刀最多涨几次大招条

**结论**：范围一刀打 5 个怪，若 **Energy Hit Cap = 3**，只涨 **3 次** Grant；多出来的怪**照样受伤**，只是不涨条。

**为啥**：无上限的话 AOE 一秒满大。范围流可以靠「这首歌 Cap 轴点高一点」变强。

| 谁 | 记什么 |
|----|--------|
| **前端** | 多怪受击时，充能 UI 跳动次数 ≤ Cap，别误导成「打几个涨几个」。 |
| **后端** | `grants = min(命中单位数, energy_hit_cap)`，再乘 Basic/卡拍倍率。 |

Cap 来自：**这首歌的模板** + 玩家在「封顶轴」上点的数。

**别做**：每刀只算 1 次充能（废范围）；无上限按人头刷（失控）。

**相关**：0002、0005
