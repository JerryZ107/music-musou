# ADR 0001 — 窗外普攻，窗内卡拍

**结论**：没跟上拍也能正常打；跟上拍 = **双倍伤害/充能** + 更快攒大招。不搞「miss 节拍就废」的音游惩罚。

**为啥**：要无双的「乱按能过」，又要跟 BGM 有收益。卡拍绑在**收益**上，不绑在**生存**上。

| 谁 | 记什么 |
|----|--------|
| **前端** | 节拍条只显示「现在在不在亮区」；不要 Perfect/Good。攻击特效分普通/卡拍两档。 |
| **后端** | 每次攻击标记 `basic` 或 `beat_on`；`beat_on` 时伤害和 Grant ×2（见 0008）。大招只看能量满不满。 |

**别做**：miss 节拍大幅减伤 / 扣血；换一套完全独立的出招表代替普攻。

**相关**：0002、0007、0008、0010
