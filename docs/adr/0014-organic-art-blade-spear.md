# ADR 0014 — H5 有机笔刷美术 + 长刀旋斩 / 长枪半扫

**结论**：Web 场景继续用 **PixiJS**，角色、道具与地面用 **高分辨率 Canvas 矢量笔刷**烘焙成贴图（椭圆 / 胶囊 / 径向渐变），**近战武器是挂在角色上的独立 Sprite**。1 号 **长刀**攻击时绕角色转一整圈，2 号 **长枪**从肩侧扫到身前半圆。刀光只描弧，不把路径闭合回圆心。判定几何仍按 [ADR 0013](./0013-web-h5-circle-hit-volume.md) 的全圆 / 半圆。攻击距离常数不变；**Hit Volume 按 Q 版身体收紧**，接触没有旧的杂兵大光环。

**为啥**：格子 `fillRect` 地面、十字虚线、喷泉同心圆和院名字会看起来像调试原点；把 Attack Volume 填成扇形饼会在角色脚下画出圆心。整套 AI 立绘难跟运行时旋刀对齐。程序笔刷能保证一局内风格统一，武器 Sprite 才能转起来。

| 谁 | 记什么 |
|----|--------|
| **前端** | 地面：整块底色 + 重叠草团 / 圆头土路；广场与院落是软椭圆，无描边环、无文字。近战：刀柄锚点旋转；拖尾 `arc` + `stroke`，先 `moveTo` 弧起点。 |
| **后端** | 命中仍是 `dist <= attackR + enemyR`。攻击距离常数不变。Hit Volume 按 Q 版身体收紧，接触无额外半径。 |

**别做**：逐格铺地、十字准星、喷泉靶心、扇形饼特效、把攻击画成从圆心连出去的半径线；也不为旋刀去换一套无法旋转的外部立绘。
