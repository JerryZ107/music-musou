# ADR 0004 — 大招几种原型 + 星元只记加点

**结论**：大招就**少数几种机制**（全屏爆、突进、分身…），每首 **Track** 绑一种，用参数表微调。**星元** = 这首歌的加点存档，**不是**英雄。

**为啥**：每首歌全新大招做不起；差异化靠「曲库 × 模板 × 加点」。

| 谁 | 记什么 |
|----|--------|
| **前端** | 选歌界面展示「这首歌什么大招」；播大招**不要**换 BGM。 |
| **后端** | `ultimate = f(track.archetype, hero, loadout)`。星元只读写 `point_allocation`。 |

**别做**：每 Hero 一首歌；星元当角色养成用。

**相关**：0005、0010
