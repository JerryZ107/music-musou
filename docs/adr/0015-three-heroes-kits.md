# ADR 0015 — 三个角色套装，局中切换不停歌

**结论**：旧「三武器攻击模组」改为 **三个角色**：**铁铠武士**、**青衫枪客**、**灵耳弓使**。选关可多选，局中 **1/2/3 切换不停歌、不重置拍子表**，**HP 共用一条命**。大招是**当前角色**的大招。切人清掉进行中的大招 Buff，充能条保留。所有角色攻击距离为旧武器模组的 **2 倍**。

**为啥**：玩家要认的是人，不是三把匿名武器。身份差异放在外形、普攻与角色大招上；一局一首歌（ADR 0010）和一条命（ADR 0012）仍然成立。

| 谁 | 记什么 |
|----|--------|
| **前端** | 选的是角色；HUD 显示角色名。武士旋斩全圆、枪客半扫、弓使锁敌箭与分身。外形按角色换贴图。 |
| **后端** | `heroId`/`weaponId` 可变，`trackId` 不变。武士全圆 r=4 / 大招 r=8；枪客半圆 r=6（强化 +2）；弓使弹程 10。 |

**别做**：每人一首歌；切人时重播 BGM；把角色做成各算各的血条。

**取代关系**：取代 ADR 0011 的「机制全在武器上、只有一个外形」。0011 的「一条命、切模组不停歌」保留。

**相关**：0010、0011、0012、0013、0014
