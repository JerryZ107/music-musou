# ADR 0009 — 像素 Demo 约定

**结论**：用 **Protagonist Template** 表示 Hero 机制；**赢** = 清怪，**输** = 主角 HP 归零。

**和正式版差在哪（实现时别搞混）**

| | 正式版 | 现在 Demo |
|--|--------|-----------|
| 音乐 | 一局一首歌，换武器不停歌（0010/0011） | 同正式版：开局选歌，换武器不停歌 |
| 充能 | 打中才涨（0002） | 同正式版：Beat-On Hit 命中才涨，需 10 次（0012） |
| 血量 | 单角色一条命（0011） | 固定 5，切武器不变（0012） |
| 规模 | 按关卡配 | 如 48 杂兵 + 4 Boss |

| 谁 | 记什么 |
|----|--------|
| **前端** | 1/2/3 键 = 切武器（非调试）；标成「武器切换」而非「模板切换」。 |
| **后端** | `run.track_id` 整局不变；`weapon_id` 可换；`player_max_hp` 恒 5。 |

**相关**：0010、0011、0012
