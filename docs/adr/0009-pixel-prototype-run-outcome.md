# ADR 0009 — 像素 Demo 约定

**结论**：用 **Protagonist Template** 表示 Hero 机制；**赢** = 清怪，**输** = 主角 HP 归零。

**和正式版差在哪（实现时别搞混）**

| | 正式版 | 现在 Demo |
|--|--------|-----------|
| 音乐 | 一局一首歌，换人不停歌（0010） | 按 1/2/3 可能**各换一首 loop**（调试） |
| 充能 | 打中才涨（0002） | 可能「卡拍就 +1」 |
| 规模 | 按关卡配 | 如 48 杂兵 + 4 Boss |

| 谁 | 记什么 |
|----|--------|
| **前端** | 若保留 1/2/3 键，标成调试；目标态只换机制不换歌。 |
| **后端** | `run.track_id` 整局不变；`hero` 可换。 |

**相关**：0010
