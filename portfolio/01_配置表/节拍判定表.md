# 节拍判定表（Beat / Track Config）

> 核心规则：一首 Track 锁一局；所有角色共用同一张 Beat Map；切换角色不停歌。

## 1. 曲目配置

| 字段 | Track 1 电音战歌 | Track 2 欢乐颂 | Track 3 激昂 |
|---|---:|---:|---:|
| BPM | 120 | 84 | 140 |
| Loop 长度 | 16.0 秒 | 约 22.86 秒 | 约 13.71 秒 |
| 拍点数量 | 32 | 32（含装饰拍） | 32 |
| 拍点生成方式 | 规整四拍 | 人工编排（旋律拍点） | 规整四拍 |
| 节拍周期 | 500 ms | 约 714 ms | 约 429 ms |

## 2. 判定窗口

| 字段 | 数值 | 说明 |
|---|---:|---|
| 判定窗口 | ±300 ms | 拍点前后 300ms 内出手均算卡拍 |
| 判定档位 | 2 档 | 窗口内 = Beat-On；窗口外 = Basic |
| 卡拍伤害 | ×2 | Basic 1 点 → Beat-On 2 点 |
| 卡拍充能 | ×2 | Basic 命中 +1 能量 → Beat-On 命中 +2 能量 |
| HUD 亮区占比 | 18%~45% | 视觉上让玩家容易跟上拍 |
| 默认音频延迟 | 60 ms | Web Audio 接近扬声器；支持 [ ] 微调 |

## 3. 节拍槽位规则

| 规则 | 实现方式 |
|---|---|
| 一拍只强化一次 | `beatSlotKey` 按最近拍点生成唯一键，同一拍内重复攻击不重复触发 |
| 切角色不断拍 | 节拍时钟独立于角色，1/2/3 切换只换 Weapon Module |
| 换曲必须重开 | Track 在 Run 开始时绑定，局中不能换歌 |

## 4. 能量经济

| 行为 | 能量变化 |
|---|---:|
| 普通攻击命中 1 个敌人 | +1 |
| 卡拍攻击命中 1 个敌人 | +2 |
| 空挥 | +0 |
| 大招消耗（枪客/弓使） | -10 |
| 枪客强化戳击命中 | 可继续充能 |
| 武士被动护盾 | 不消耗能量 |

## 5. 设计意图

- **只有两档判定**：休闲玩家不需要追求 Perfect/Good，降低挫败感。
- **卡拍=2 倍伤害+2 倍充能**：用同一个奖励把「听歌」和「割草爽感」绑死。
- **空挥不充能**：惩罚无脑连点，逼玩家跟拍。
