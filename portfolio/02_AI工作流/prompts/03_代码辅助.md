# Prompt 05：代码辅助

## 工具
Cursor / ChatGPT / Claude

## 常用 Prompt
1. 「请用 TypeScript 实现一个圆形碰撞系统，区分攻击体积和身体体积，并编写单元测试。」
2. 「请为顶视角割草游戏设计一个波次生成器，要求 4 个 Boss 院落 + 1 个中央广场，小怪不能生成在障碍物里。」
3. 「请为 PixiJS v8 写一个角色动画切换逻辑：待机/行走两帧，按移动状态切换，并保持 zIndex 排序。」
4. 「这段节拍判定逻辑有 bug：同一拍会被重复触发。请帮我改成按最近拍点生成唯一槽位键。」

## 人工修正
- AI 初版碰撞有 bug：没有考虑目标半径容差 → 手动改为「攻击圆 vs 身体圆」。
- AI 初版波次太随机 → 手动改成固定波次，保证关卡节奏可控。
