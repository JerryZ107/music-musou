# 易上手、难精通与留存痛点总结

> 岗位关键词：中轻度休闲游戏。本文档回答三个问题：为什么好上手？为什么有深度？怎么解决留存痛点？

## 1. 一句话定位

**一首歌一局的俯视角节奏割草游戏：移动、普攻、滑步三个操作，卡拍就变强。**

## 2. 易上手设计

| 设计点 | 实现方式 | 对应体验 |
|---|---|---|
| 操作极简 | 移动 + 普攻 + 滑步，另有 1/2/3 切角色 | 10 秒内学会 |
| 判定宽松 | 只有两档判定：窗口内/窗口外，无 Perfect/Good | 不用背谱 |
| 失败温和 | 5 点血，受击无敌 0.5 秒 | 不容易暴毙 |
| 视觉引导 | 节拍条亮区 + 卡拍闪光 + 地面预警圈 | 知道何时打、何时躲 |
| 角色兜底 | 铁铠武士被动护盾 | 新手首选容错高 |

## 3. 难精通设计

| 高手技巧 | 设计支撑 |
|---|---|
| 卡拍节奏感 | 窗口内出手伤害 ×2、充能 ×2，空挥不充能 |
| 滑步无敌帧 | 110ms 无敌，但冷却 0.26 秒，用来躲丧尸冲刺和 Boss 砸地 |
| 切角色不停歌 | 三个角色共用一条命，但攻击形态不同，需要按场面切换 |
| 走位与拉怪 | 小怪有分离力，Boss 有范围预警，需要带着尸潮绕圈 |
| 能量管理 | 枪客 7 次强化戳击、弓使分身嘲讽，需要选择释放时机 |

## 4. 留存痛点与对策

| 留存痛点 | 现状问题 | 设计对策 |
|---|---|---|
| 单局目标感弱 | 目前只有清完 5 波 | 加入 3 星评价：时间、最大连击、无伤 Boss |
| 重复游玩动力不足 | 3 首曲子、1 张地图 | 曲目解锁 + 每日挑战 + 周常 Boss |
| 失败惩罚不明确 | 输赢只有文案 | 加入广告复活（Demo 预留了 Ad Revive 概念） |
| 成长感缺失 | 没有局外成长 | 每个 Track 增加 Allocation 加点模板，自由分配攻击范围/充能上限 |
| 社交传播弱 | 单机 | 加入战绩分享卡 + 好友排行 |
| 操作疲劳 | 长时间割草容易累 | 单局控制在 3 分钟内，波次间有 5 秒缓冲 |

## 5. 留存漏斗设计（建议）

1. **D1 首日**：10 秒上手 → 第 1 波教学 → 第一次卡拍秒怪 → 第一次 Boss 胜利。
2. **D3 前 3 天**：解锁第二首曲目 → 尝试枪客/弓使 → 完成 3 星评价。
3. **D7 前 7 天**：每日挑战 + 广告复活 + 战绩分享。
4. **D30 长线**：曲目轮换、Allocation 加点深度、节日 Boss。

## 6. 面试话术

- 「这款游戏的易上手来自三件事：操作少、判定宽、视觉反馈直接。」
- 「难精通来自四个隐藏技巧：卡拍节奏、滑步无敌、切角色不停歌、拉怪走位。」
- 「中轻度休闲游戏最大的留存痛点是目标感弱，所以我设计了 3 星评价 + 曲目解锁 + 每日挑战的漏斗。」
- 「我不只写玩法，也考虑 D1/D3/D7/D30 的留存节奏。」
