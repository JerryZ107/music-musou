# 留存反馈设计说明

面向休闲游戏策划岗，Web Demo 已实现的局内数据反馈与留存意图。

## 1. 连击（Combo）

| 项 | 设计 |
|---|---|
| 触发 | 玩家本体命中敌人（分身命中不计连击） |
| 断连 | 2.4 秒内无命中清零 |
| 展示 | HUD `连击 ×N`（N≥2 时 pulse 动画） |
| 留存 | 短窗口连击制造「再来一刀」心流；结算展示最高连击引导复玩 |

## 2. 伤害飘字

| 项 | 设计 |
|---|---|
| 触发 | 任意对敌伤害（含子弹、爆炸） |
| 表现 | 世界坐标上浮淡出；卡拍显示 `4!` 高亮 |
| 留存 | 即时数值兑现，强化卡拍价值感知 |

## 3. 三星结算

| 星级 | 条件（胜利） |
|---|---|
| ★☆☆ | 通关 |
| ★★☆ | 剩余 HP≥3 且 最高连击≥5 |
| ★★★ | 剩余 HP≥4 且 最高连击≥10 且 卡拍命中≥8 |

分数 = 总输出 + 最高连击×40 + 卡拍×25 + 剩余 HP×150

**留存意图**：三维目标（生存 / 操作 / 节奏）给复玩理由，避免「赢了就关」。

## 4. 成绩分享

- 按钮：**复制成绩分享**
- 文案含：曲名、星级、分数、连击、卡拍、**在线试玩 URL**
- 存档槽记录 `bestScore` / `bestStars`

**留存意图**：轻量社交传播 + 自我挑战（刷分 / 刷三星）。

## 5. 面试话术

「我把休闲游戏常见的连击、飘字、星级和分享做进可玩 Demo，不是为了堆功能，而是验证：**正反馈是否足够密、目标是否足够清晰、失败后是否还想再来一局**。」
